Context științific

De ce este studiat

MOTS-c este o peptidă derivată mitocondrial, descrisă ca produs al unei regiuni codante din ARN-ul ribozomal mitocondrial 12S. Este investigată în modele privind homeostazia energetică, răspunsul celular la stres și comunicarea dintre mitocondrie și nucleu.

Model experimental

Mecanism investigat

Cercetarea urmărește căi de semnalizare metabolică, inclusiv răspunsuri asociate AMPK, adaptarea la stres și modificări ale utilizării substraturilor energetice.

Interpretare responsabilă

Limitele dovezilor

O mare parte din dovezi provin din sisteme celulare și modele animale. Extrapolarea către oameni sau către un produs comercial nu este justificată fără date și autorizări specifice.

Rezumatul este informativ și descrie contextul de cercetare; nu reprezintă o afirmație medicală sau o recomandare de utilizare.
