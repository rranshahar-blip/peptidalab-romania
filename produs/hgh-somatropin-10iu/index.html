Context științific

De ce este studiat

Somatropina este forma recombinantă a hormonului de creștere uman și este o proteină, nu o peptidă RUO obișnuită. În cercetare este utilizată pentru studierea receptorului hormonului de creștere și a axei GH–IGF-1.

Model experimental

Mecanism investigat

Legarea de receptorul GH activează căi de semnalizare celulară, inclusiv JAK2/STAT, cu efecte experimentale dependente de țesut și model.

Interpretare responsabilă

Limitele dovezilor

Somatropina este substanță activă medicamentoasă reglementată. Listarea rămâne blocată comercial până la clasificarea juridică și verificarea unui lanț de aprovizionare autorizat.

Rezumatul este informativ și descrie contextul de cercetare; nu reprezintă o afirmație medicală sau o recomandare de utilizare.
